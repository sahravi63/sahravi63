**QR-GRPO: Critic-Free Quantum Reinforcement Learning via Group Relative Policy Optimization with Variational Quantum Circuits**
R. Sah, A. Ansari, M. Jagadeesh · *4th IEEE International Conference on Industrial Electronics: Developments & Applications (ICIDeA 2026)* · Presented, Paper ID 336

- Variational quantum circuit policy trained with critic-free GRPO using only **16 trainable parameters**
- On CartPole-v1 (8 seeds), reached **64.8%** of classical GRPO's return with 16 vs. ~250 parameters, with the **lowest training variance** of all methods (CV 0.093 vs. 0.305 for PPO)
- 8-configuration encoding ablation: removing data re-uploading cut return by 71%; a 2-qubit design beat the 4-qubit baseline

**🧩 Reliable AI Knowledge Layer** · `Python` `LangGraph` `ChromaDB` `RAGAS` `Streamlit`
Self-correcting multi-agent RAG pipeline for an HR/procurement policy assistant: routing, per-chunk relevance grading, query rewriting, web-search fallback and claim-level hallucination grading. Resolves conflicting policies using version, effective-date and "supersedes" metadata, returning **VERIFIED / CONFLICTING / INSUFFICIENT EVIDENCE** instead of guessing. Ablation framework across 5 pipeline variants with RAGAS faithfulness scoring; pluggable Groq, OpenAI, Anthropic and Gemini backends.

**🩸 HemaSight: Needle-free Anaemia Screening** · `Python` `scikit-learn` `NumPy` `Flask` `IBM LinuxONE` · *IBM Z Datathon 2026*
Screens for anaemia from phone photos of the inner eyelid, palm and fingernails using colour features, fusing per-site models into a screen / uncertain / refer decision. **AUC 0.93**, haemoglobin MAE **1.39 g/dL** under leave-one-hospital-out validation across 10 hospitals. Runs natively on IBM LinuxONE (s390x) with a pure-NumPy ResNet-18. Open source (MIT).

**💰 Personalized Financial Assistant** · `MongoDB` `Express` `React` `Node.js` `Chart.js` `LLM APIs`
Full-stack MERN app for income and expense tracking with Chart.js dashboards, LLM-powered spending insights, a finance chat assistant and forecasts (Groq Llama 3.1 with Gemini, OpenAI and Anthropic fallbacks). JWT + role-based admin access, bcrypt, Helmet, rate limiting; deployed on Vercel.

**📑 PDF Data Extraction** · `Python` `Flask` `Google Cloud Vision` `Vercel`
Extracts text from PDFs, images and DOCX files with cloud OCR for scanned pages, auto-redacts personal data with partial masking, and translates output into English, Hindi or French. Bundle cut to ~45 MB for Vercel serverless.
